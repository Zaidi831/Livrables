# Analyse des ventes d’une librairie (Python)

## Objectif
Analyser les ventes d’une librairie afin d’identifier les produits et clients les plus contributeurs,
suivre le chiffre d’affaires et proposer des recommandations business.

## Données
Données de ventes (transactions, produits, clients).  
Nettoyage et préparation avant analyse.

## Démarche
- Nettoyage et exploration des données (EDA)
- Création d’indicateurs (KPI) : chiffre d’affaires, top produits, top clients, BtoB
- Visualisations pour interpréter les tendances
- Synthèse et recommandations actionnables

## Outils
Python (Pandas, Matplotlib)

## Livrables
- Notebook / script d’analyse
- Visualisations
- Synthèse des recommandations
