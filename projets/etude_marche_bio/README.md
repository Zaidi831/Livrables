# Étude de marché – Produit bio

## Objectif
Identifier des pays cibles pour le lancement d’un produit bio à l’international
à partir de données macro-économiques et d’une analyse structurée.

## Données
- Données FAO
- Données Banque mondiale
- Indicateurs macro-économiques sélectionnés

## Démarche
- Analyse PESTEL pour le choix des variables
- Nettoyage et préparation des données
- Analyse en composantes principales (ACP)
- Segmentation des pays par clustering (K-means)
- Interprétation des groupes et recommandations stratégiques

## Outils
Python (Pandas, ACP, K-means)

## Livrables
- Analyses statistiques et graphiques
- Segmentation des pays
- Recommandation de marchés cibles
